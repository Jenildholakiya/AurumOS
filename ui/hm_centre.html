How to get the Gmail app password
  1. Open the shop's Gmail in a browser and go to Google Account → Security.
  2. Turn on 2-Step Verification first — Google only shows app passwords after this.
  3. On the same Security page open App passwords (type it in the search box if you cannot see it).
  4. Create one: app Mail, device Windows Computer (or Other → AurumOS), then Generate.
  5. Copy the 16-letter code (xxxx xxxx xxxx xxxx) and paste it into App password above — spaces do not matter.
  6. Your normal Gmail password will not work here — Google blocks it. Only the app password sends mail.
